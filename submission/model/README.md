# 로컬 정적 자산

다음 파일은 생성 라벨·가공 자료를 포함하므로 공개 저장소에서 제외합니다. 기존 작업 폴더의 동일 경로에서 복원하거나 대회에서 허용한 공유 경로로 확보하십시오.

- `item_guides.json`: 24항목의 배포 자료 기반 판정 기준
- `examples.json`: 제공 dev 근거 기반 부분라벨 사례
- `reviewed_examples.json`: 원문과 정답을 대조한 추가 사례
- `provenance.json`: 자산 출처와 생성 방법 기록
- `review_specs.json`: 추가 사례 생성기의 로컬 검토 선택 목록

마지막 파일은 원래 `tools/build_v4_examples.py`에 포함되어 있던 검토 데이터만 분리한 것입니다. 생성 로직과 v4 추론 코드는 유지했습니다. `review_specs.json`은 `[공고ID, 항목번호, 기존라벨, 문서번호, 원문구절, 검토설명]` 배열들의 JSON 배열입니다. 사실 확인 없이 내용을 만들어 채우지 마십시오.

제출 ZIP에는 처음 네 JSON만 포함하며 검토 선택 목록은 개발용입니다. 모델 가중치를 이 폴더에 넣지 않습니다.
