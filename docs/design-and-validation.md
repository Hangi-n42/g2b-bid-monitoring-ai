# v4 설계와 검증 범위

## 판정 방법

고정 모델의 가중치는 변경하지 않는다. 항목을 세 그룹으로 나누고 각 그룹에서 적용 조건, 실제 사실, 예외의 범위를 확인하도록 구성했다. 참가자격과 평가 배점, 실제 구매품목과 자격코드, 영리기업 규모 제한과 비영리법인 예외를 구분한다.

그룹별 원문 선택은 원본 문서의 위치를 유지한다. 출력 스키마의 근거 번호 범위는 실제 요청의 구절 개수에 맞춘다. 다른 그룹이나 공고의 번호로 근거를 복원하지 않는다. 불완전한 응답은 제한적으로 재시도하고 실패를 전부 정상 판정으로 대체하지 않는다.

사례는 현재 그룹과 관련된 부분라벨만 제시한다. 자기 ID·동일 본문과 메타데이터·지정 제외 ID는 검색에서 제외한다. 검색 관련성을 우선하고 작은 항목 다양성 가점을 준다. 모든 항목에 사례를 균등 배정하거나 양·음성 쌍을 강제하는 방식은 아니다.

## 참고 연구

| 원논문 | 설계에 참고한 내용 |
|---|---|
| [Factoring Statutory Reasoning, ACL 2021](https://aclanthology.org/2021.acl-long.213/) | 법령 적용 판단의 구성요소 분해 |
| [Chain of Logic, Findings of ACL 2024](https://aclanthology.org/2024.findings-acl.159/) | 복합 규칙과 예외의 논리관계 구분 |
| [Lost in the Middle, TACL 2024](https://aclanthology.org/2024.tacl-1.9/) | 긴 입력에 근거가 있어도 활용이 보장되지 않는 문제 |
| [Least-to-Most Prompting, ICLR 2023](https://arxiv.org/abs/2205.10625) | 복합 문제의 분해; 현재 독립 그룹 방식은 순차 알고리즘의 재현이 아님 |
| [Revisiting Demonstration Selection, ACL 2024](https://aclanthology.org/2024.acl-long.492/) | 예시 선택 효과의 모델·과제 의존성 |
| [Rethinking the Role of Demonstrations, EMNLP 2022](https://aclanthology.org/2022.emnlp-main.759/) | 예시의 입력 분포·라벨 공간·형식 역할 |
| [Active Example Selection, EMNLP 2022](https://aclanthology.org/2022.emnlp-main.622/) | 양·음성 수의 균형이 항상 우월하지 않음 |

외부 논문은 방법론을 이해하기 위한 참고이며 논문 데이터·법령·가중치를 제출 자산에 반입하지 않았다. 이 연구들로 현재 대회의 성능 향상을 입증할 수는 없다.

## 검사 결과

첫 그룹 구현에서는 문맥 축소 때문에 근거 보존이 39/54로 감소했다. 원문 우선 정책과 입력 예산을 조정하여 회귀를 제거했다. 최종 입력량은 v3보다 약 56.15% 많다. 실행시간이 같은 비율로 증가한다고 단정할 수는 없다.

원본 베이스라인을 검토했지만 원본의 실제 점수를 재현한 대조 실험은 없다. 실제 고정 모델의 dev F1과 최종 v4 점수 개선도 이 검사에서 확인하지 않았다. 공개 dev를 이미 설계에 참고했으므로 검색 fold 제외 검사는 완전히 미관측인 일반화 성능이 아니다.

분석 보고서의 공고별 원문·라벨과 생성 자료는 공개하지 않고 요약 수치만 기록한다. 검토자는 AI 에이전트이며 실제 사람 또는 법률전문가 검수로 표현하지 않는다.
